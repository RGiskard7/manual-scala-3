## Manual Definitivo de Scala: Índice Secuencial (0 a Experto)

### Módulo 1: The Scala Way (Fundamentos Híbridos)

| Capítulo                                              | Nombre del Capítulo                                                                                                                                                                                            | Breve Descripción |
| :---------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :---------------- |
| **1. Configuración y Tooling Esencial**               | Instalación de Java JDK, uso del intérprete REPL (Read, Evaluate, Print, Loop) y configuración de `sbt` o `Scala CLI` para proyectos modernos.                                                                 |                   |
| **2. El Paradigma Híbrido: POO Pura y PF**            | Entendimiento de que **todo es un objeto** y **toda función es un valor de primera clase**. La inmutabilidad como principio central (`val` vs `var`) para sistemas concurrentes seguros.                       |                   |
| **3. Modelado de Datos: Clases, Objetos y Traits**    | Uso idiomático de `class`, `object` (Singleton/Companion) y `trait` para interfaces y composición. Introducción a la potencia de `case class` para modelado de datos inmutable y eliminación de _boilerplate_. |                   |
| **4. Funciones y Control de Flujo como Expresiones**  | Definición de funciones, funciones anónimas (lambdas) y **Funciones de Orden Superior (HOFs)**. Uso de `if-else` y bloques de código como **expresiones que retornan un valor**.                               |                   |
| **5. Estructuras de Datos y Colecciones Funcionales** | Dominio de colecciones inmutables (`List`, `Set`, `Map`) y operaciones funcionales (`map`, `filter`, `fold`, `reduce`). Diferencias clave con colecciones mutables (`Array`).                                  |                   |
| **6. Pattern Matching y ADTs Básicos**                | La herramienta `match` para desconstruir estructuras anidadas y complejas. Introducción a los **Tipos de Datos Algebraicos (ADTs)** mediante `sealed trait` o la sintaxis `enum` de Scala 3.                   |                   |

### Módulo 2: Scala Funcional Moderna (Tipado y Abstracciones)

| Capítulo                                                       | Nombre del Capítulo                                                                                                                                                                                                         | Breve Descripción |
| :------------------------------------------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :---------------- |
| **7. Manejo de Ausencia y Errores Puros**                      | Sustitución de `null` por el tipo `Option[T]` para valores ausentes. Uso de `Try[T]` y `Either[E, R]` para manejar éxito o fracaso como **valores tipados**, evitando excepciones (`throw`).                                |                   |
| **8. Abstracciones Contextuales (Scala 3: `given` y `using`)** | **Reemplazo del mecanismo `implicit`** de Scala 2 por palabras clave enfocadas en la **intención**. Fundamentos de cómo `given` define valores canónicos y `using` los consume automáticamente.                             |                   |
| **9. Type Classes y Métodos de Extensión**                     | Implementación de patrones de **Type Classes** (como `java.util.Comparator` en Java) usando `given instances`. Uso de la sintaxis `extension` de Scala 3 para añadir métodos a tipos existentes.                            |                   |
| **10. Tipos Avanzados de Scala 3: Estructura y Flexibilidad**  | Exploración de `Union Types` (`A \|B`) y`Intersection Types`(`A & B`) para flexibilidad de tipado. Uso de`Opaque Types` para crear nuevos tipos de costo cero en tiempo de ejecución.                                       |                   |
| **11. Metaprogramación y Optimización de Compilación**         | Uso de `inline` para forzar la expansión de código en tiempo de compilación (optimización de rendimiento). Introducción a la manipulación de **ASTs** (Árboles de Sintaxis Abstracta) mediante Quoting y Splicing (Macros). |                   |

### Módulo 3: El Ecosistema Industrial (Backend y Reactividad)

| Capítulo                                                | Nombre del Capítulo                                                                                                                                                                                                 | Breve Descripción |
| :------------------------------------------------------ | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | :---------------- |
| **12. Concurrencia: Futures y el Monad IO**             | Manejo de la asincronía con **`Future`** (la mónada que representa un valor que estará disponible en el futuro). Introducción a la Programación de **Efectos Puros** (IO Monad) y las **Fibras** (threads ligeros). |                   |
| **13. Arquitectura de Efectos: Cats Effect vs ZIO**     | Comparativa de los dos principales _stacks_ funcionales. El tipo `ZIO[R, E, A]` (Entorno, Error, Valor) y el manejo de inyección de dependencias con `ZLayer`.                                                      |                   |
| **14. Desarrollo Web Funcional**                        | Integración de librerías HTTP modernas como `http4s` (basado en Cats Effect) y definición de APIs con **Tapir** para describir _endpoints_ y generar documentación OpenAPI automáticamente.                         |                   |
| **15. Modelo de Actores: Pekko Fundamentos y Patrones** | Introducción al **Modelo de Actores** de Apache Pekko (el _fork_ de Akka). Arquitectura de actores como **unidades de computación aisladas** que se comunican por mensajes asíncronos (`tell`).                     |                   |
| **16. Pekko: Tolerancia a Fallos y Estado**             | El patrón de **Supervisión** (la jerarquía _let it crash_) para la tolerancia a fallos. Implementación de actores con estado (stateful vs stateless actors).                                                        |                   |
| **17. Sistemas Distribuidos y Persistencia Reactiva**   | Uso de **Cluster Sharding** para distribuir entidades (actores con estado) a través de un clúster. Implementación del patrón **Event Sourcing** con Pekko Persistence para la recuperación de estado.               |                   |

### Módulo 4: Ingeniería de Datos y Calidad (Maestría Aplicada)

| Capítulo                                                         | Nombre del Capítulo                                                                                                                                                      | Breve Descripción |
| :--------------------------------------------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :---------------- |
| **18. Apache Spark: El Dominio de Big Data**                     | Rol de Scala como lenguaje nativo de **Apache Spark**. Creación de `SparkSession` y diferencia fundamental entre RDDs, DataFrames y Datasets tipados.                    |                   |
| **19. Programación de Datos Estructurados con Spark**            | Manipulación de DataFrames utilizando la API de Scala: selecciones (`select`), filtrado (`filter`), agregaciones (`groupBy`) y ejecución de consultas SQL programáticas. |                   |
| **20. Abstracciones de Datos: JDBC Funcional (Doobie)**          | Conexión a bases de datos con un enfoque funcional puro utilizando la librería **Doobie** (Functional JDBC layer).                                                       |                   |
| **21. Diseño de Estructuras y Algoritmos Avanzados**             | Profundización en la inmutabilidad y estructuras de datos persistentes (_Homegrown Collections_). Análisis teórico de complejidad y notación O(n).                       |                   |
| **22. Testing de Calidad y Property-Based Testing**              | Introducción a **ScalaCheck** para testing basado en propiedades (PBT), para validar la corrección del código en lugar de solo los ejemplos.                             |                   |
| **23. Tooling de Ingeniería y Arquitectura (sbt y Modularidad)** | Configuración avanzada de `sbt` (_multi-project builds_). Uso de herramientas de refactorización y _linting_ como **Scalafix** para imponer estándares de código.        |                   |
